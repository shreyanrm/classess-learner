# Getting help on a question

**Ask for help as often as you like. It never costs you progress, and Wobo starts with a question rather than the answer.**

**The ladder**

1. **Try again.** No penalty, no counter.
2. **Get help.** Wobo asks you the one question that usually unsticks this, and draws a ring around the part of the screen it is about.
3. **Why was my answer wrong?** Wobo takes what you actually did and shows where it breaks, using your numbers, not a generic list of common mistakes.
4. **Show me.** After two misses Wobo offers the answer and then asks whether you want to see why. If you say yes, Wobo walks it in small steps with a choice at each one, drawing as it goes.

**Wobo draws on the control itself**

When Wobo says "this square", a ring appears on that square. When Wobo means the point at the intersection, an arrow lands there. The equation is written in Wobo's hand beside the graph, not in a panel somewhere else.

**Asking for help is recorded as a good thing**

Your progress page counts asking for help after a wrong answer as resilience, because it is. Nothing about your mastery is reduced for using help; what changes is that Wobo brings the idea back later to check it stuck.

**When a mistake keeps coming back**

Wobo builds the exact demonstration that breaks the belief behind it, using your own numbers, then flags it to re-test in a few days.
