# 03 · Create (the create-anything door)

**Purpose:** turn a learner-defined goal into a verified, ontology-mapped course (see `03-FLOWS/06-create-anything-flow.md`).
**Contains:** a calm prompt (text/voice) · moderation feedback · a "compiling your course" state (honest, no fake progress) · the resulting
node sequence shown as a fresh (mostly monochrome) constellation the learner is placed into · hand-off into Learn.
**States:** prompt · moderating · compiling · verifying · placed · teaching · unverifiable (graceful: offer the closest verified path).
**Vidya:** curious/anticipatory choreography while compiling (a gentle hovering "thinking", flame trailing); celebrates the new map appearing.
**Events:** `create.request.submitted.v1`, `create.course.compiled.v1`, `create.node.mapped.v1`.
**AI:** `safety.moderate` · `plexus.compile` · `ontology.map` · `verify.*`.
**Guardrails:** Plexus is the only content source; nothing served unverified; moderation before generation acts; simulators only from
pre-verified parametric templates.
