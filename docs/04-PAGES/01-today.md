# 01 · Today (the ritual home)

**Purpose:** the gym-habit anchor. Calm, premium, one clear thing to do. "I did my Wobo" lives here.
**Contains:** today's single **next-best action** (one CTA, magnetic); the **meter** (concepts budget, calm); today's **win** (or the
invitation to earn one); a **constellation peek** (the map gaining color); a gentle streak/ritual marker (honest, no FOMO).
**States:** fresh-day · mid-session · real-win-earned · budget-low · returning-after-gap (warm, never guilt) · un-elevated (no behavioural
nudges) vs elevated.
**Wobo:** greets per the cute license — a small drift-in and settle, an ember flame while waiting; never blocks the next action.
**Events:** `session.started.v1`, `meter.session.opened.v1`, reads mastery_cache + next-best.
**AI:** `mastery.getNextBestNode`; (elevated) `archetype.classify` for copy/timing framing only — never price, never for under-18.
**Guardrails:** one honest next action, not a feed; no infinite scroll; no guilt notifications; aspiration-led copy; no exclamation marks.
