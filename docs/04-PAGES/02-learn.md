# 02 · Learn (the heart)

**Purpose:** run the pose→struggle→reveal loop (see `03-FLOWS/02-learn-flow.md`).
**Contains:** OpenerCard (active interactive prompt via JSXGraph/Mafs/custom) · CanvasSurface (working area Wobo perceives) ·
WoboPresence/Panel (on demand) · RevealPanel (fading reveal) · attempt history · modality-switch affordance · ignite + constellation on mastery.
**States:** monochrome-enter · pose · struggle · stuck→wobo · reveal · modality-switched · practice-gate · ignite · constellation · advance ·
error/offline (preserve canvas state) · reduced-motion.
**Wobo:** the richest stage for the cute license — she leans toward the working when thinking, escalates hint posture (flame brightens
with hint level), squishes/celebrates with a flame-flare on a win, dims to ember during unaided moments. Identity fixed; choreography free.
**Events:** the full learn-loop set (`learn.*`, `wobo.*`, `practice.item.served.v1`, `mastery.band.changed.v1`).
**AI:** `generate.opener` (verified) · `orchestrator.step` (switch/forward/frustration) · `wobo.turn` · `grade.attempt` · `verify.*`.
**Guardrails:** never explain-first; never serve unverified content; Wobo never hands the answer; canvas state persisted; mastery ends the loop.
