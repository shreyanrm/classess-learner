# 04 · Icons & Illustration

## Icons (use a premium market set — do NOT hand-draw a full set)
- Use a high-quality set (Phosphor is the quality level; Lucide acceptable). Consistent weight, 2px-friendly.
- **What makes them ours is the treatment, not the drawing:** icons live monochrome and take on a concept's accent only when that
  concept is mastered (the ignite logic applies to iconography too).

## Illustration / interactive artifacts
- Prefer **live interactive artifacts** (JSXGraph, Mafs, R3F) over static illustration — the product *builds*, it doesn't decorate.
- Where illustration is needed, keep it monochrome-line + earned-color, consistent with the thesis. No stocky 3D blobs, no gradients-for-vibe.
- **Annotation kit** (Caveat hand-drawn marks, from the motion system) is the primary "human" visual texture — lean on it.

## Cached video nuggets (Remotion 4)
- 15–30s, library not spine. Monochrome system chrome; content earns color. Consistent type + annotation kit. Captioned. Calm VO, no hype.
