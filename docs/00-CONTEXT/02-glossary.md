# 02 · Glossary (use these terms exactly)

- **Ecosystem** — the Dot eVentures education ecosystem; the entity. Citizens plug in.
- **KGtoPG** — the platform citizen: governed identity + data + intelligence platform. Its own product. NOT Learner's database.
- **Classess Learner** — the flagship B2C app (this build). Learners only.
- **Plexus** — the content/generation engine and sole content source, grounded on Indian-board catalogs (NCERT ~3,500 items). No static banks.
- **The atom** — one topic taught perfectly end to end before breadth. First atom: linear equations in one variable. The proof gate.
- **Vidya** — the signature on-screen tutor (molten jelly presence + frosted panel). Sees the learner's work, graduated hints, persistent memory.
- **The orchestrator** — the per-step policy picking modality/difficulty/repeat-or-advance until mastery. Heuristic now, learned (Track 2) later.
- **Mastery bands** — not-started / emerging / developing / secure / independent.
- **Ten gap types** — prerequisite, conceptual, procedural, application, retention, language, accuracy, speed, confidence, support-dependency.
- **Evidence Graph** — the evidence-linked record of conclusions about a learner.
- **Ignite** — the signature moment: a monochrome concept floods to its color on mastery.
- **The meter** — the behavioural daily free-session budget (concepts mastered, not time).
- **Archetype engine** — silent per-learner classifier driving copy/reward/paywall framing/timing (never price).
- **Knowledge twin** — the queryable model of the learner's own cognition.
- **Platform intelligence layer** — the shared event-driven intelligence/data layer beneath KGtoPG (always this generic name).
- **Track 1 / Track 2** — Track 1 = external market LLMs per feature; Track 2 = proprietary fine-tuned + edge SLMs (margin/moat). Never conflate.
- **Event contract** — the immutable, attributed event envelope every app emits upward. The highest-stakes seam.
