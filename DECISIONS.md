## Engineering decisions (made to keep building, reversible)

- **2026-07-06 · Typeface.** Google Sans Flex is not distributable via Google Fonts. The UI ships with a self-hosted variable font stack that matches its metrics and voice, declared as `"Google Sans Flex", "Google Sans Text", system-ui` — the moment a licensed Google Sans Flex file is provided, dropping it into `apps/web-pwa/public/fonts/` activates it with zero code change.
  - **2026-09-03 · amended, now true.** The stand-in faces (Plus Jakarta Sans + Caveat) were a Google Fonts `<link>`, not self-hosted, which contradicted this decision and put a font CDN in the CSP. They now ship as bundled `@fontsource-variable` packages imported from `src/main.tsx` and served from our own origin; `font-src` is `'self'` alone. The stack is `"Google Sans Flex", "Google Sans Text", "Plus Jakarta Sans Variable", "Plus Jakarta Sans", system-ui` — Google Sans Flex still leads, so the drop-in above is unchanged.
- **2026-07-06 · Wobo's rig.** Rive is the target for the production rig; authoring a .riv binary requires the Rive editor. Wobo's body ships as a hand-built SVG + spring-physics rig (Framer Motion) implementing the full state machine (listening / thinking / explaining / celebrating / resting) behind a `WoboBody` interface — a Rive rig can replace the internals later without touching any consumer.
- **2026-07-06 · Voice.** Gemini Live voice requires `GEMINI_API_KEY` in the gateway environment. The voice path is built and wired; without the key it degrades to text seamlessly (no error surface, per the verification-gate philosophy).
- **2026-07-06 · Catalogs.** CBSE, ICSE, and Telangana State Board catalogs (subjects → chapters → topics, classes 6–10) are generated from model knowledge of the official syllabi and marked `provenance: "model-knowledge"` pending verification against official documents. All other boards are listed as doors with on-demand fetch, per the directive.
- **2026-07-06 · The one pigment.** DESIGN.md reserves ultramarine `#1F35E0` for brand and mastery; the old 14-accent subject palette is retired. All mastery ignites are ultramarine; molten belongs to the tutor alone and appears nowhere else (identity lock updated to the law hex `#FF5A1F`, tests updated); magenta and acid await earned moments.
- **2026-07-06 · XP economy (v1).** item 10 · boss 80 · topic 150 · account 50 · profile photo 20 · invite friend/parent 40 · mystery 60 · bonus 45. One-time awards guarded by onceKey. XP is presentation currency only — mastery truth stays in the evidence→band pipeline; no new event types were added to the immutable contract.
- **2026-07-06 · Route IA.** onboarding · home (front door) · learn · practice · subject(id, intent) · course(topicId) · sandbox(topicId?) · progress · you. No persistent rail anywhere; ⌘K palette + Wobo reach everything.
- **2026-07-06 · Did-you-know.** Served from a curated seed list rotating deterministically by day (fresh daily per the directive); live-generation via the gateway can replace the list without UI change.
- **2026-07-06 · Catalog verification source.** Khan Academy's NCERT-aligned course trees (e.g. khanacademy.org/math/ncert-math-class-9-new) are the sanctioned cross-check for the generated catalogs (owner directive). Verification pass queued for a Sonnet labor agent; catalogs keep `provenance: model-knowledge` until it runs.
- **2026-07-06 · Graphics system.** No stock illustration. Generative "concept sigils" (deterministic geometric line-art per topic id, igniting ultramarine on mastery), hand-drawn subject glyphs, chapter filigrees, and empty-state constellations — `apps/web-pwa/src/ui/art.tsx`. Art is identity, not decoration, and scales to every topic with zero assets.

## Picked from the Classess School platform doc (2026-07-06 — owner said take what adds value)

- **Explainable intelligence as product law.** Every Wobo recommendation/proactive chip carries: why it appeared, the evidence behind it, a confidence band, and what ignoring it costs. Nothing Wobo suggests is a black box. (Folded into the wave-4 orchestrator missions.)
- **The full workflow loop with a measured tail.** Observe → interpret → recommend → approve → execute → **outcome → learn**: Wobo's suggestions record whether they were taken and whether they worked (events), so the next recommendation is sharper. 
- **"I think I'm right" re-grade path** on evaluated answers (boss + practice): the learner can contest, Wobo re-examines with the verifier, and dignity is preserved either way.
- **Preventive evaluation (Mode 3).** Snap-a-problem / show-your-work BEFORE submission: graduated hints to fix it themselves — never the final answer, never forced. Queued as the multimodal wave-5 flagship.
- **Trajectory view for the twin.** Actual path solid, predicted path dotted — "where you're heading" as quiet hero art, recalculated per measurable moment.
- **Hyperlocalization framing for the engines.** Generated examples use locally familiar money/food/cricket contexts per board and region — relevance, not translation.

- **2026-07-06 (afternoon) · Design system, second cut (owner-directed).** Pure white canvas, black text, cool neutrals, vibrant brand-accent pops; subtle 3px radius on every card/button/chip/input; one button system (solid ink/tonal/ghost, fixed heights, 4px magnetic pull); end-to-end viewport layouts (padding, not boxed max-widths); entrance choreography (cascade/rise staggered springs with de-blur) as the page-load signature; Google Sans + Caveat. Overrides DESIGN.md §2 values where they conflict.

Home = the learner's day as one continuous drawn path with data-driven stops (continue, next, review, boss gate, mystery spur), Wobo walking it. - **2026-09-02 · Rebrand: Classess Learner → Wobo.** The product is now **Wobo**, and the tutor formerly called Vidya is now **Wobo** too — one name for the app and for the tutor who lives in it. Body, voice, and behaviour were kept; only the name changed. (Superseded 2026-09-03 on the pronoun question — see the no-gender entry below.) Identifiers moved with it: the package is `@wobo/wobo`, the capability is `wobo.turn` (the legacy `vidya.turn` name is aliased on the gateway for one release so the deployed bundle keeps working), and the law docs are `WOBO.md` and `WOBO-CAPABILITIES.md`. The **Classess** name is retained only for the ecosystem and its B2B products (Classess Teacher, Classess School), and only in internal architecture prose that has to name them; the "internal identifiers" half of this entry was superseded on 2026-09-03 by plan §17. Contract event types carrying the old name were renamed pre-launch: no production event lake existed and the Supabase project was paused at the time, so no replay or migration was owed.

- **2026-09-03 · Wobo has no gender (plan §19, owner).** Wobo is a wobot, not a boy or a girl. Every word we write or generate leads with the name ("Wobo draws", "ask Wobo"); they/them only where a pronoun is unavoidable; never she/her or he/him, in product copy, prompts, docs, code comments, tests, marketing or legal. Wobo speaks of itself as "I", and answers the direct question — "I'm a wobot, neither" — warmly, briefly, and moves on. Everything written before this date was rewritten to comply, and CI now fails on a gendered pronoun near "Wobo".

- **2026-09-03 · Code names follow the brand (plan §17).** The rename went below the product surface: `@classess/*` → `@wobo/*`, `classess_gateway`/`classess_verifier`/`classess_contracts`/`classess_atom` → `wobo_*`, `ClassessEvent` → `WoboEvent`, `--clss-*` → `--wobo-*` across ~1,500 custom properties, every storage key and custom event name, with a one-shot boot-time localStorage migration so an installed PWA keeps its state. `CLASSESS_IMAGE_CACHE_DIR` keeps a warn-once read-the-old-name shim for one release. The three live-platform names (the Railway service, the Vercel project, the Supabase project) are the remaining owner actions; the two committed strings that carry the Railway hostname stay until the service is renamed, or production loses its gateway.

- **2026-09-03 · Three brand gates in CI.** `bun run gate` runs them, and CI fails on any of them: **no-classess** (the old brand or the `clss-` prefix anywhere outside git history, `docs/history/`, the WOBO-TASKS ledger and a per-line allowlist), **white-label** (a provider, model, or vendor name in the built web bundle, in a gateway string a client can see, or in user-facing package copy), and **pronouns** (a gendered pronoun within 60 characters of "Wobo"). Every exception carries a written reason in `scripts/gate_allowlist.py`, so an exception is a decision on the record rather than a silent grep tweak.

- **2026-09-03 · Palette v4 retires the molten body (DESIGN.md §2/§4, owner).** Wobo is the ink-visor wobot, and the warm body colour is gone: the tutor is a deep-navy ink body (`#14142B`) carrying a cream visor (`#FAF7F0`) on paper, inverted on night (cream `#F3F0E8` body, night `#0F1226` visor), with Wobo-blue eyes and pen tip (`#2B45FF`, lifting to `#7C8CFF` on night) as the one pigment on the character. This supersedes the "molten belongs to the tutor alone" half of the 2026-07-06 entry above: the tutor no longer wears molten, so molten reserves nothing. The lock lives in code at `packages/wobo/src/identity.ts` and the rig reads its default tones from there rather than restating them (`packages/wobo/src/body/palette.ts`); `identity.test.ts` asserts the tones literally against the law, asserts the rig reads them, and scans every source file in the package (comments stripped) so the retired jelly/squircle/molten/flame vocabulary and its hexes cannot come back. `@wobo/config` still ships `accent.molten` as a general-purpose accent token; it is simply no longer Wobo's.
